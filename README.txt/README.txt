LEARN AI – PROJECT INFORMATION
==============================

Project Title:
LearnAI – AI-Powered Competency Intelligence

Main Entry Page:
dashboard.html

Project Overview:
LearnAI is a web-based competency intelligence platform designed to
provide an interactive dashboard for competency tracking, analytics,
learning resources, courses, recommendations, and AI-powered features.

Project Structure:
• dashboard.html    – Main dashboard / entry page
• competency.html   – Competency-related information
• recommendations.html – Personalized recommendations
• generate.html     – AI content generation
• analytics.html    – Analytics and progress insights
• courses.html      – Learning courses
• materials.html    – Learning materials
• demo-data.html    – Demo data
• about.html        – Project information

Note:
dashboard.html is the primary page of the project and serves as the
main entry point for accessing the available features.
